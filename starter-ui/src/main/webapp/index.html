Payara Starter

Payara Starter is a source code generator to create new Payara Server or Payara Micro projects. It allows you to quickly and easily start with Payara Platform!

Take advantage of customisation options: select your chosen JDK versions, Jakarta EE profiles, build tools, Docker support, and more. Payara Starter will also streamline your project by integrating with popular IDEs.

Simply select your options, and click ‘Download project’ - and Payara Platform is ready to use.

Platform
Platform
The Jakarta EE version and profile, Payara Server or Payara Micro and its version, and the Java version. Each choice narrows the ones below it.

The Jakarta EE release to compile against. Azul Payara 7 doesn’t support versions older than 10.

Jakarta EE Profile How much of Jakarta EE the project uses: Platform is the full API, Web Profile the subset for web applications, Core Profile the minimal set for microservices.

Needs Jakarta EE 10 or later

Core Profile has no security or ER Diagram Designer, so both are turned off in Features.

Payara Payara Server is a full application server. Payara Micro runs the application from a single JAR, suited to microservices and containers.

The Payara release to target, as published on Maven Central. The list follows the Jakarta EE version.

The Java version to build and run with. The list follows the Jakarta EE and Payara versions; Azul Payara 7 doesn’t support Java older than 11.

Features
Features
All optional: MicroProfile APIs, a login, Docker support, and JPA entities and REST endpoints generated from an ER diagram.
MicroProfile Add MicroProfile Config, OpenAPI, Fault Tolerance and Metrics. Full MP selects all four.
Reads configuration from property files, environment variables and system properties.
Publishes an OpenAPI description of the application’s REST endpoints.
Retries, timeouts, circuit breakers and fallbacks for calls that can fail.
Exposes application and runtime metrics over HTTP.
Security How users log in: no login, or form authentication against a file realm, a database or LDAP.

Security configuration is not available with Jakarta EE Core Profile.

Login No login, or a login form that checks users against a file realm, a database or an LDAP directory.


Deployment Adds Docker support to the generated project.

ER Diagram Pick or generate an ER diagram with AI help; Starter turns it into JPA entities and REST endpoints.

ER Diagram Designer is not available with Jakarta EE Core Profile.

Start from one of the sample diagrams, or describe a new one in Diagram Builder & Live Preview.

Generate Code For: Each layer needs the ones before it: without JPA nothing else is generated, without Repository no REST or Web, without REST no Web.
